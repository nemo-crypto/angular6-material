# 六节实践课

1. **启动与路由**：阅读 main.ts，观察 loadComponent 如何拆分页面；刷新 `/courses` 验证开发服务的 SPA 回退。
2. **数据契约**：阅读 course.ts，增加一个课程字段前先定义边界并写测试。不要把本地 JSON 直接视为可信对象。
3. **Signals 状态**：从 CourseStore 找到唯一课程状态，解释 stats 如何派生；练习增加“剩余学习分钟数”。
4. **响应式表单**：尝试空名称、非整数分钟和超范围输入，确认不能新增。练习增加分类筛选而不复制课程数组。
5. **Material 交互**：打开删除对话框，分别取消与确认；解释 afterClosed 的作用。练习用一个共享对话框支持新的确认操作。
6. **测试与适配**：运行 check 和 test:e2e，查看移动截图。练习增加一个路由页面，并补充从主导航到页面的测试。

验收：不连接任何业务服务器即可运行；修改刷新后保留；失败状态可见；新增功能不依赖关闭 strict 或绕过校验。
